AKMAL & AZREEN — WEDDING INVITATION

Files:
- index.html
- style.css
- script.js
- wedding-animation.mp4

To preview:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html using Live Server (recommended).

The envelope opens when tapped/clicked. The wedding animation loops silently, then guests scroll to the formal invitation, countdown, venue link, and RSVP link.

Mobile notes:
- Designed responsively for Android and iPhone browsers.
- Video is muted to support autoplay. Some browsers may pause media due to battery/data settings.

When you choose the song, add the audio file to this folder and the music player can be added. Mobile browsers usually require a tap before audio can start.
